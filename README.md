# Common Wrapper

The repository contains a common wrapper that serves as the main entry point.

The wrapper:

1. Displays the list of available assignments.
2. Allows the user to select an assignment.
3. Compiles the selected assignment driver.
4. Launches the selected assignment menu.
5. Handles invalid selections gracefully.

# Test File Conventions

- Every test file contains exactly one test case.
- Test files are stored inside the corresponding assignment folder.
- Test files use sequential naming conventions.
- Multiple test cases are executed through the assignment driver.

---

# Runtime Measurement Policy

Only algorithm execution time is measured.

The following operations are excluded from timing:

- File reading
- Input parsing
- Memory allocation used as setup
- Data structure conversion/preprocessing
- Output formatting
- Output file generation

Execution time is reported in milliseconds (ms).

---

# Output Files

Outputs generated by an assignment are stored inside the corresponding assignment's `outputs` directory.

---

# Error Handling

Drivers and wrappers provide clear error messages for:

- Missing input files
- Invalid test selections
- Invalid menu choices
- Compilation failures
- Output file creation failures
